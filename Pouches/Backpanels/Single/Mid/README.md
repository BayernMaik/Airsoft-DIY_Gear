<h2>
<a id="id_description"></a>Molle Backpanel (Mid Cut)</a>
<a href="#id_navigation" style="color: #dddddd; text-decoration: none">&#x21B0;</a>
</h2>
<img src="./Preview1.png" border="1"></img><br>
&#x26A0; Preview Image will be added soon
The Molle Backpanel server as a Platform to attach Frontflaps to assemble a Pouch. The assembled Pouch then can be attached to any Molle Host System like Plate Carriers, Chest Rigs, etc.

<h3>
<a id="id_instructions" style="color: #dddddd; text-decoration: none;">Instructions</a>
<a href="#id_navigation" style="color: #dddddd; text-decoration: none;">&#x21B0;</a>
</h3>
Place the Female Velcro Patch on the Molle Panel and sew it in place as displayed below.
<img src="./Instructions1.svg" border="1"></img>
The Molle Panels Loops can now be looped in the Molle Cuts on the Panels Back. The Velcro on front will hold the Flaps attached to the Panel.
